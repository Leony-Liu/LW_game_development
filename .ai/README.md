# Codex 过程文件

`.ai/` 集中保存 Codex 专用的辅助脚本、生成快照和隔离自动化数据。仓库级协作契约仍是根目录 `AGENTS.md`；本文件仅说明文件归属与放置方式，不建立第二套全局指令。

| 路径 | 职责与维护方式 |
| --- | --- |
| `scripts/` | 维护并纳入版本控制的 Codex 专用过程脚本；不是玩法源码或通用项目工具 |
| `generated/` | 生成快照等产物，默认忽略；现有 `PROJECT_DUMP.md` 原样迁入，内容不会随源码自动更新 |
| `runtime/` | 隔离的自动化用户数据、临时环境、日志、截图与验证证据，默认忽略；保留有用历史数据 |
| `tmp/` | 任务级探针、草稿和可丢弃中间文件，默认忽略；完成任务后清理新建的一次性文件 |

稳定项目工具 `tools/godot_cli.ps1` 保持原位，其 `APPDATA`、`LOCALAPPDATA`、`TEMP` 和 `TMP` 指向 `.ai/runtime/` 下的相应目录。Godot 管理的 `.godot/`、资源、场景及用户维护文件保持原位。隐藏目录 `.ai/` 不作为 Godot 资源目录使用；源码快照生成器也排除整个 `.ai/`，避免嵌入运行数据、备份或旧快照。

## 生成源码快照

在项目根目录执行（Windows 也可将 `python` 换为 `py -3`）：

```powershell
python .ai/scripts/build_godot_snapshot.py
```

默认项目根目录从脚本位置向上定位，不依赖终端当前目录；默认输出 `.ai/generated/PROJECT_DUMP.md`，相对输出路径以选定项目根目录为基准。显式项目目录、`-o` / `--output`、`--max-file-mb` 和 `--no-line-numbers` 保持可用。主动运行生成器会更新指定输出，生成前应保留需要留存的旧快照。快照只代表生成时的文件状态，不是测试结果或实时实现依据。
